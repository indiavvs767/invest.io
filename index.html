About CapitalDoc

We are a demonstration platform designed to showcase modern UI/UX for investment websites. This is an educational redesign of a broken GitHub Pages site.

Our goal with this rewrite was to fix broken links, improve layout, add proper responsiveness, create clean cards for plans, and deliver a professional structure that can be used as a portfolio piece.
